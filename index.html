02Design choices

The interesting part of this project isn't the parsing — it's the decisions about what the tool should not do. Click a card to read more.

Constraint

Local-first by design

No network, no telemetry, no auto-update.

The tool reads only the file you drop on it and writes only the export next to the source. Nothing else touches disk. No registry writes, no background service, no subprocess. Files never leave the machine — because they can't.
Trust

Fidelity scoring

The tool tells you when it isn't sure.

Every parse produces a confidence score based on how much of the source the classifier understood versus silently skipped. Below 99%, the score is clickable and drills into the specific items that were flagged. Reviewers know exactly when to double-check before trusting the output.
Engineering

HEI/Refi toggle without re-parsing

Both report variants, computed once.

The Home-Equity workflow hides the first deed of trust from the verbatim list. Instead of re-reading the PDF when the toggle flips, the parser computes both views up front and the UI swaps between them instantly. Same input, two reports, zero duplicate work.
Discipline

Four bugs fixed from the prototype

Found by testing against real commitments.

The Python prototype was ported for parity, then hardened. Amounts ending in .00. no longer split into phantom items. The word "Hudson" no longer counts as HUD. "Heirs" no longer trips the IRS detector. Scanned PDFs now warn instead of showing a false all-clear.
Environment

Built for IT review

The constraints were designed in, not bolted on.

Self-contained single-file exe. asInvoker manifest — no admin prompt. No registry writes. No logs, no cache, no background service. Bundle is signed off with a hash and a clean Defender scan. Submitted to internal IT for approval.
Usability

Click-to-copy, everywhere

Built for people who paste into case management systems all day.

Every line in the report is one click from the clipboard. Arrow keys navigate, Enter or Space copies the highlighted row. The top-bar chips copy too — file number, DOT total, cloud total. No selecting, no Ctrl+C, no fiddling.
